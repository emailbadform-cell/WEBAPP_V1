# BTC15M Web V2.24.7 Full Upload Package

This package is a packaging correction for Web V2.24.7.

It contains the complete deployable Web V2.24.7 runtime at the repository root plus the available V2.24.7 support/research-history artifacts under `support/`.

No Kalshi private key, `.pem`, `.key`, `.env`, `__pycache__`, or `.pyc` files are included.

The live web runtime files at repository root remain authoritative. The `support/` directory is included to avoid the aggressively stripped-down deployment package while preserving the same V2.24.7 runtime logic.
