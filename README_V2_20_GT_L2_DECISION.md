# BTC15M Web V2.20 / Research Interface V10.34

Adds the operational Ghost Thread lifecycle, predictive no-current-side Decision, live L2 consensus, future-timestamp protection, stateful Forward hysteresis, cheap cache-only health endpoint, and Candle #2 conditional preview. Individual OF and L2 venues remain hidden from the main UI; only consensus is shown. L2 does not alter Forward, Decision, MP, TR, Chart, FLIP or GT direction authority.

L2 consensus is derived from free public BTC/USD order-book snapshots from Coinbase, Kraken, Bitstamp and Gemini. It is display/research context until prospective validation proves incremental predictive value.
